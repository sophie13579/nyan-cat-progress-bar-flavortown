# Privacy Policy

Last updated: February 18, 2026

Nyan Cat Progress Bar for Flavortown does not collect, store, transmit, or sell personal data.

## What this extension does

This extension runs only on `https://flavortown.hackclub.com/*` and replaces Flavortown progress bar visuals with a Nyan Cat themed progress bar.

## Data collection and use

- No personal data is collected.
- No analytics or tracking is used.
- No browsing history is collected outside the declared host.
- No user data is sold or transferred to third parties.

## Remote code

All JavaScript, CSS, and image assets are packaged within the extension.
No remotely hosted code or WebAssembly is executed.
